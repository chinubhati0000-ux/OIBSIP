# Landing Page — Tata Motors (Concept Redesign)

## Track
Web Development & Designing — Level 1, Task 1

## Objective
A visually polished static landing page built with HTML5 and CSS3, showcasing foundational
layout, typography, and responsive design skills. This project is a concept redesign inspired
by Tata Motors' brand identity, created for learning purposes as part of the OIBSIP internship.

## Tech Stack
- HTML5
- CSS3 (Flexbox and Grid, no JavaScript needed for layout)

## Features
- Sticky navigation bar with 3 links
- Hero section with headline, subheadline, and call-to-action button
- Two content sections: Features and Testimonials
- Footer with placeholder contact and social links
- Consistent colour palette (navy blue with an electric blue accent)
- Fully responsive layout for desktop and mobile
- Clear typographic hierarchy (Space Grotesk headings, Inter body text)

## How to View
Download or clone this folder and open `index.html` in any web browser.
No build steps or dependencies are required.

## Disclaimer
This is a concept redesign created for educational purposes as part of a web development
internship task. It is not an official Tata Motors product and is not affiliated with Tata Motors.
